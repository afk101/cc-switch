# 01 — 收口共享供应商保存高层接口

**What to build:** 将 Codex 共享供应商保存收口到 Codex Profile 路由模块的单一高层接口。用户可观察到的数据库保存和主供应商模型目录同步保持不变，但命令层不再负责组合引用同步、提交顺序和补偿细节，为后续完整同步提供稳定测试缝隙。

**Blocked by:** None — can start immediately

**Status:** resolved

- [ ] Codex 共享供应商保存通过一个高层接口完成，调用方不需要了解 Profile 发现、锁顺序、文件计划或补偿步骤。
- [ ] 非 Codex 应用继续使用原有供应商保存行为，不受此次 prefactor 影响。
- [ ] 现有 Codex 供应商校验、规范化和持久化规则保持不变。
- [ ] 现有主供应商引用模型目录同步行为保持不变。
- [ ] 现有前端交互、Tauri 参数形态及数据库 schema 保持兼容。
- [ ] 高层接口拥有一个使用内存数据库和临时 Profile Home 的行为测试，证明数据库与模型目录仍能通过同一入口更新。
- [ ] 既有相关测试全部通过，不新增仅验证私有辅助函数调用顺序的脆弱测试。

## Answer

Codex 共享供应商保存已收口到 Profile 路由模块的高层接口，命令层只负责按应用类型委托和转换错误。既有数据库保存与主引用模型目录同步现在通过该接口验证，非 Codex 行为和外部调用契约保持不变。
