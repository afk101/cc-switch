# 02 — 补齐跨平台导出韧性边界

**构建内容：** 日志导出在下载目录异常、空日志、同名目标、运行中轮转、符号链接和写入失败等真实环境中保持可预测：能安全回退或尽力完成，无法完成时不留下半成品。

**受阻于：** 01 — 打通一键导出日志主路径。

## 覆盖范围

- REQ-04、REQ-05（同名避让）、REQ-06（桌面回退）、REQ-07、REQ-10、REQ-11、REQ-12、REQ-15。
- SCN-03、SCN-04、SCN-05、SCN-06、SCN-07、SCN-08、SCN-09、SCN-11。

## Acceptance Criteria

- [x] 下载目录无法解析、不是可用目录或无法创建输出时自动回退桌面；两者均不可用时显示失败。
- [x] `logs` 不存在或无可归档普通文件时提示“暂无可导出的日志”，不生成空 ZIP。
- [x] 同名目标自动追加递增序号，已有文件内容不被覆盖。
- [x] 遍历不跟随或归档符号链接，不读取 `logs` 树外内容。
- [x] 文件清单固定快照长度；持续追加不会让导出无界运行，轮转、缩短或消失的文件可静默跳过。
- [x] 瞬时跳过不出现在完成提示中，也不暂停代理或日志写入。
- [x] 权限、磁盘、ZIP 完成或落位失败时不留下最终命名半成品，不破坏既有 ZIP，按钮恢复可重试。
- [x] Windows、macOS、Linux 目标目录和 ZIP 条目行为保持可移植。

## 验证方式

- 从归档服务公开 seam 验证空目录、同名、追加、缩短/消失、符号链接、写入失败与临时文件清理。
- 从命令公开 seam 验证下载目录到桌面的回退顺序及双失败结果。
- 从设置面板公开交互 seam 验证无日志与通用失败提示、以及失败后按钮恢复。
- 运行相关 Rust/前端聚焦测试、完整前端测试、完整 Rust 测试、类型检查和格式检查。

## 执行约束

- 修改生产代码或测试前必须调用并遵循 `$tdd`，逐个边界完成 red → green。
- 只静默跳过因快照后变化导致的源文件问题；目标目录、ZIP writer、finish 和落位错误仍为整体失败。
- 临时文件与最终文件必须位于同一目标目录，以支持可靠落位；任何失败都由生命周期自动清理。
- 不为了严格一致性暂停日志、代理、路由或其他运行服务。

## 范围之外

- 导出前敏感内容确认、脱敏和跳过数量报告。
- 进度、取消、保存位置选择和打开目录操作。
- 修改日志保留或清理策略。
