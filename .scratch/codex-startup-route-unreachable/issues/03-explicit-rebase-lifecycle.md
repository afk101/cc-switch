# 03 — 显式路由操作重建最新基线

Status: ready-for-agent

**构建内容：** 用户主动启用、切换供应商或关闭路由时，以操作意图正确处理最新Home：显式新接管建立新backup，关闭恢复最近基线，外部接管后的关闭不回写陈旧配置。

**受阻于：** 02 — 启动恢复安全收敛外部接管。

## 覆盖范围

- `REQ-02`、`REQ-10`、`REQ-11`、`REQ-12`、`REQ-17`
- `SCN-11`、`SCN-12`、`SCN-13`、`SCN-14`、`SCN-20`、`SCN-21`

## Acceptance Criteria

- [ ] 显式重新启用以操作当刻Home建立新backup并清除外部接管状态。
- [ ] 已启用期间显式切换供应商时，以当前Home替换旧基线并继续完成切换。
- [ ] 后续关闭只恢复最近基线的严格路由字段，保留关闭瞬间最新非路由字段。
- [ ] 已外部接管后显式关闭不恢复陈旧backup，只清理路由状态。
- [ ] 非显式供应商切换流程绝不修改model；显式切换允许应用目标供应商model。
- [ ] 任一步骤失败时既有补偿恢复本次操作前状态，不退回更早基线。

## 验证方式

- 运行启用→外部编辑→显式切换→关闭的端到端manager测试。
- 运行缺失Home基线的启用→关闭测试。
- 运行持久化、Home写入、runtime切换失败注入测试。

## 执行约束

- 修改生产代码或测试前调用 `$tdd`。
- 新backup必须在Home接管写入前进入可恢复生命周期。
- `model`授权严格绑定用户显式切换到另一供应商的动作。
- 保留Profile故障转移引用和在途请求既有语义。

## 范围之外

- 不增加运行期配置监控。
- 不更改共享供应商保存对其他Profile的事务语义。
