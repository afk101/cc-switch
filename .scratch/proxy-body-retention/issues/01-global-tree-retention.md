# 01 — 建立全局树级按日清理

**Status:** resolved

**构建内容：** 为整个 body dump 固定两层日志树提供安全、best-effort 的按日清理能力，使根层遗留日志和所有 Profile 的过期标准日志都能在一次调用中收敛。

**受阻于：** 无——可以立即开始。

## 覆盖范围

- 覆盖 `REQ-01`、`REQ-02`、`REQ-06`、`REQ-07`、`REQ-08`、`REQ-09`、`REQ-11`。
- 覆盖 `SCN-01`、`SCN-02`、`SCN-03`、`SCN-04`、`SCN-05`、`SCN-06`、`SCN-07`、`SCN-08`、`SCN-12`。
- 交付 `TS-01`，并形成后续 maintenance 接入所依赖的稳定清理接口。

## Acceptance Criteria

- [ ] 根层以及任意一层真实 Profile 目录中的过期标准 dump 在一次清理后均被删除。
- [ ] 当天、未来日期、畸形文件、其它扩展名、symlink、特殊文件、第二层内容和空目录均保持不变。
- [ ] 根目录不存在时不创建目录并成功返回。
- [ ] 并发 `NotFound` 不产生失败；其它逐项错误不阻止剩余文件处理，并形成有界摘要。
- [ ] 不增加容量淘汰、无限递归、跨进程锁或新外部依赖。
- [ ] regression test 在生产实现前能因现有局部清理行为变红，完成后转绿。

## 验证方式

- 运行 body dump 模块定向测试，验证完整固定两层 fixture 的文件保留与删除结果。
- 运行并发/错误路径定向测试，验证幂等与 partial success。
- 运行 Rust 格式检查和该模块可用的编译检查。

## 执行约束

- 修改测试或生产代码前调用 `$tdd`，逐个 vertical slice 执行 red → green。
- 只进入恰好一层真实目录；不跟随 symlink，不使用通用递归删除。
- 只有严格匹配命名且早于本地今天的普通文件可删除。
- 新常量必须进入项目统一常量模块；新增函数保持单一职责，新增注释使用中文。
- 不删除任何已有注释或 commented-out code。

## 范围之外

- 应用启动和 24 小时 timer 接线。
- 从请求路径移除旧 retention 调用。
- 当天容量上限、空目录回收和 UI 配置。
